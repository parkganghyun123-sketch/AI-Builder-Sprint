## 한눈에 보기

## 기능 0. 접속

로그인·회원가입 없이 링크로 바로 시작 (세션만). 두 경로 중 선택.

### 페이지: 홈 `/`

| 버튼 | 동작 | 이동 |
|---|---|---|
| **계약서를 받았어요** | 경로 A 시작 (사진 업로드) | → `/upload` |
| **계약서를 못 받았어요** | 경로 B 시작 (조건 직접 입력, AI 미사용, 문서상태 `draft`) | → `/review?path=B` |

---

## 기능 1. 계약서 사진 확인 (조건 추출·확정)

사진에서 시급·근로시간 등 조건을 자동 추출하고, **사람이 최종 확정**한다.

### 페이지: 업로드 `/upload` (단계 2·3)

| 버튼 | 동작 | 이동 | 비고 |
|---|---|---|---|
| **사진 선택 / 촬영** | 파일 선택·카메라로 이미지 1장 | — | |
| **업로드** | 서버 전송 → Document Parse + Information Extract | → `/review` | 처리 중 "읽는 중…" 표시, 버튼 비활성 |
| **다시 촬영** | 미리보기 취소 | — | 화질 불량·실패 시 |
| **직접 입력할게요** | 수동 입력 폼 폴백 | → `/review?path=B` | **추출 3회 실패 시** 노출 |
| 뒤로 | 홈 | → `/` | |

### 페이지: 확인·수정 `/review` (단계 4 ⭐)

| 버튼 | 동작 | 이동 | 비고 |
|---|---|---|---|
| **항목 수정(인라인 입력칸)** | 추출값 수정 | — | 모든 항목 편집 가능. AI 저신뢰 항목은 노란색 강조 |
| **확인하기 / 조건 확정** | 확정값을 검증 엔진(B)에 전달 | → `/result` | 필수 항목 미입력 시 비활성 |
| **확인 요청 보내기** | (경로 B) 사장에게 확인 요청 | — | `draft`→`requested` (워터마크), 회수·재발송 가능 |
| 뒤로 | 업로드 | → `/upload` | |

> 이 화면의 값이 "사람이 확정한 값". 이후 계산·문서생성은 전부 이 값 기준.

---

## 기능 2. 법정 기준 자동 검증

확정된 조건을 최저임금·주휴수당·휴게시간 기준과 대조 (코드 계산, AI 아님).

### 페이지: 결과 `/result` (단계 5)

| 버튼 | 동작 | 이동 | 비고 |
|---|---|---|---|
| **제대로 된 계약서 만들기** | 확정값+표준양식으로 수정본 생성 | → `/contract` | 위반 유무와 무관하게 진행 가능 |
| **조건 다시 수정** | 확인·수정으로 되돌아감 | → `/review` | |
| (항목별) **이 조항 넣어 수정본 만들기** | 특정 누락 조항 반영 | → `/contract` | 챗봇 답변 카드와 동일한 행동 버튼 |

> 표시 숫자·판정·근거는 **검증 엔진 반환값만**. 프론트 계산 금지. 계약 사실 vs 법정 기준 구분, "2026년 기준" 표기. 1350 상시 문구 고정.

## 기능 3. 계약서 생성 + 전자서명 체결

문제를 발견하는 데서 끝나지 않고 수정본을 만들어 양쪽이 서명한다.

### 페이지: 수정본 미리보기 `/contract` (단계 6)

| 버튼 | 동작 | 이동 | 비고 |
|---|---|---|---|
| **미리보기 확인** | 생성된 계약서 미리보기 | — | 서명 전 = "근로조건 확인 요청서"로 표기 |
| **서명 요청하기** | 서명 단계로 | → `/sign` | |
| **조건 다시 수정** | 결과/수정으로 | → `/review` | |
| 초안 다운로드 | 초안 PDF 저장 | — | **"확인 전 초안" 워터마크** 강제 |

### 페이지: 전자서명 `/sign` (단계 7)

| 버튼 | 동작 | 이동 | 비고 |
|---|---|---|---|
| **상대방 연락처 입력** | 사장/알바생 연락처 입력칸 | — | 발송 후 마스킹(개인정보 최소화) |
| **서명 요청 발송** | 모두싸인 서명 요청 발송 | — | "서명 대기", 문서상태 `confirmed` |
| **내가 서명하기** | 본인 서명 진행 | — | 서명 캔버스/모두싸인 위임 |
| **재발송 / 회수** | 요청 재전송·취소 | — | 상대 미서명 시 |
| (완료 시) **체결 완료로** | 양쪽 서명 완료 | → `/complete` | 문서상태 `signed` |

> 모두싸인 연동 실패 시 자체 서명 캔버스로 폴백. 서명 실행은 사용자가 직접.

### 페이지: 체결 완료 `/complete`

| 버튼 | 동작 | 이동 | 비고 |
|---|---|---|---|
| **계약서 다운로드** | 체결 PDF 저장 | — | 워터마크 없음(정식 문서) |
| **보관함으로** | 보관함 이동 | → `/archive` | |
| 처음으로 | 홈 | → `/` | |

## 기능 4. 보관 (증빙)

체결 문서와 판정 이력을 저장해 나중에 꺼내 쓴다.

### 페이지: 보관함 `/archive` (단계 8)

| 버튼 | 동작 | 이동 | 비고 |
|---|---|---|---|
| **문서 열기** | 체결 계약서 상세 | — | 상태 뱃지 함께 표시 |
| **다운로드** | PDF 저장 | — | |
| **판정 이력 보기** | 검증 결과 이력(읽기전용) | → `/result` | "나중에 꺼내 쓸 증빙" |
| **새 계약서 확인** | 새 흐름 시작 | → `/` | |

## 공통 UI (모든 결과·서명·보관 화면 고정)

- **상시 노출 문구** — 1350 안내 (`LegalDisclaimer`)
- **문서 상태 뱃지** — `draft`(회색)/`requested`(주황+워터마크)/`confirmed`(파랑)/`signed`(초록) (`DocumentStatusBadge`)
- **스텝퍼** — 현재 단계 표시 (`ScreenShell`)

### 상태 전이 (버튼이 문서 상태를 바꾸는 지점)

```
draft ──[확인 요청 보내기]──▶ requested ──[사장 확인]──▶ confirmed ──[양쪽 서명 완료]──▶ signed
(작성 중)                    (확인 요청됨)              (조건 확인됨)                   (체결 완료)
                              +워터마크                  서명 전                        보관 가능
```

## 이번 범위에서 뺀 버튼 (기획서 MVP 제외)

로그인/회원가입 · 사장님용 대화형 입력 · 다국어 전환 · 근무기록 대조.
